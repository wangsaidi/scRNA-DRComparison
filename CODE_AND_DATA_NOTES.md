# Code and Data Notes

The package preserves the final figure/table source data and the scripts used to assemble the visual materials.

Recommended public-release checks before uploading to GitHub:

1. Confirm that no controlled-access raw datasets are included.
2. Add environment files if the final repository should support full reruns from raw data.
3. Add a `LICENSE` file selected by the authors.
4. Add a citation file (`CITATION.cff`) after the manuscript metadata are finalized.
5. Add external dataset download instructions matching the manuscript data-availability statement.
