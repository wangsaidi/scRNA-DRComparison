# Benchmark Figure and Source-Data Release

This directory is organized as a GitHub-ready companion package for the dimensionality-reduction benchmark manuscript.

## Contents

- `figures/main/`: final main figures in PNG, PDF, and SVG formats.
- `figures/supplementary/`: final supplementary figures in PNG, PDF, and SVG formats.
- `source_data/main_figures/`: source data used to generate the main figures.
- `source_data/supplementary_figures/`: source data used to generate the supplementary figure atlas.
- `source_data/supplementary_tables/`: CSV source tables for all supplementary tables.
- `tables/`: compiled supplementary table workbook.
- `docs/`: supplementary-figure Word document and table-caption documents.
- `code/`: scripts used to assemble figures, tables, and targeted sensitivity analyses.
- `config/`: configuration files for benchmark reruns and analysis routing.

## Notes

High-resolution TIFF files are stored in the sibling `submission_high_resolution_figures/` folder in the full materials package, not here, to keep the GitHub release lightweight.
Before public release, add the final repository license, citation metadata, and any dataset-access instructions required by the manuscript's data-availability statement.
